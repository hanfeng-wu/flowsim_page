# FlowSim Project Page

Static project page for **FlowSim: Rendering-Free Closed-Loop Simulation for Evaluating End-to-End Driving Systems**.

Open `index.html` directly in a browser, or serve locally:

```bash
python3 -m http.server 8000
```

- `static/images/` – figures exported from the paper
- `static/videos/` – counterfactual simulation GIFs
- `static/css/style.css` – page styles
